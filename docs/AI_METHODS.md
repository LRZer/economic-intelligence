# AI 方法、时间边界与复现

## 中国月度研究

研究对象是全国 CPI/PPI 同比与环比、制造业 PMI、新订单 PMI、非制造业商务活动指数。
这些指标各自有稳定定义和相对完整的月度序列；不把年度、累计值或新旧口径拼入训练。

对目标自然月 `t`，输入是同一指标在 `t−1、t−2、t−3、t−12` 的读数，以及月份的正余弦。
任何必需滞后值缺失则跳过该月，不前填、不插值。使用训练内 StandardScaler 与
Ridge(alpha=10)，至少24个有效训练样本，最多120个先前样本。每个评估月重新拟合，
训练标签严格早于目标月。特征无需未来读数；测试覆盖未来值扰动不改变此前预测。

最后12个自然月固定为留出期。之前的逐期预测为开发验证期，至少6期；留出至少8期。
开发期在上期值与去年同月值之间选择基线，留出期不参与选择。界面仍展示两种基线，
研究门槛要求模型留出 MAE 同时低于两基线，且与开发期选定基线的配对误差差值区间完全低于零。
该门槛是审慎的研究筛选规则，不代表投资效力或显著性的保证。

报告 MAE、RMSE、样本量和逐期训练范围。经验误差带来自开发期绝对预测误差，采用有限样本
分位数、向上取位，目标为名义90%。留出期覆盖率单独报告；时序误差不独立，未来覆盖没有保证。
配对误差差值使用固定seed=42的循环移动块抽样：3个已评估月为一块，重复2000次。
它保留部分短期相关性，但不重新训练，也不处理模型选择、结构突变和数据修订。

解释图展示标准化特征乘线性系数的加性贡献；贡献总和加截距等于预测值。
它解释模型如何计算，不证明经济因果。

## 本期异常核查

Isolation Forest 使用本期读数、较上月差及较去年同月差作为特征。
200棵树、固定seed=42、contamination=0.1，历史窗口最多60个有效样本、至少24个。
只在本期之前的样本上拟合，然后评分本期。本期不参与阈值或树的训练。
负分数触发原文及经济冲击复核；不自动修正或删除值。
没有经过标注的异常真值，因此不报告准确率、召回率或“识别经济危机”的结论。

## WDI 全球年度 GDP 研究

目标是某经济体下一年度实际 GDP 增速。输入为严格上一年度的 GDP 增速、通胀、
失业率、资本形成/GDP、经常账户/GDP，以及前两年度 GDP 增速。
采用 HistGradientBoostingRegressor：100轮、7叶、learning_rate=0.05、L2=10、seed=42。
跨国池化训练，不宣称所有国家遵循同一经济机制。缺失特征由树原生处理，目标缺失不填补。

开发期固定2015—2019，留出期固定2020—2024；每年只训练之前年度的标签。
基线使用上一年度 GDP 增速。展示全球 MAE/RMSE、样本数、国家数、逐年度比较与单国回测。
全局误差可能由样本多的经济体及异常冲击主导；需要同时核查年度和国家结果。
研究门槛要求每个留出年度都超过基线，仍不足以证明未来稳健。

经验区间使用开发期绝对误差90%分位，另报告留出覆盖率。
特征解释采用2019年开发样本的置换重要性，3次置换、seed=42；不使用留出标签挑选特征。
最新研究估计必须展示目标年度、训练截止和缺失特征数；年报发布时间滞后，不可冒充实时预测。

## DeepSeek 证据摘要

本地模型完全不需要 API。付费摘要默认关闭，确认费用和发送范围后才设置
`ENABLE_PAID_AI=1`。凭据仅从运行环境或部署者安全配置读取；仓库没有真实密钥。
全球研究的可选摘要只发送最多20个白名单公共证据条目，总体最多12KB；中国月度页面使用本地证据模板，没有付费生成按钮。禁用付费模式时不查找环境、Secrets或文件凭据。2026-10-06本人首次12题真实受限计划试点通过，详见[结果补充](LLM_BUSINESS_PILOT_RESULTS.md)；仅证明已查看开发问题的计划与本地工具链路。全球摘要、月度报告编排与开放式金融分析质量仍未实测；网页证据问答未改为付费LLM。
请求 JSON 格式，核验结构、每条观察引用的证据id、空引用、未知引用及文字中未经验证的数字。
不符合要求的输出拒绝展示，原始数据与本地模型保持可用。通过引用核验也不等于语义审核。

连接/读取超时为10/60秒；仅遇到429时最多重试一次；不重试可能已经计费的读取超时。
错误提示不回显凭据、请求正文或响应正文。测试使用占位凭据和mock，不产生API费用。

## 共同局限与复现

所有当前评估基于已保存的修订版快照，尚未恢复每个历史时点真实可获得的数据版本。
“特征在目标期之前”消除数值上的未来泄漏，但不能消除历史修订与发布日期造成的实时可用性偏差。
没有宣称因果、交易收益、生产级保证，也没有把 IMF 官方预测当作模型训练的实际标签。
