# BIS 有效汇率：月度跨国比较口径

## 数据与范围

观澜使用国际清算银行（BIS）的[有效汇率主题页](https://data.bis.org/topics/EER)和[官方批量 CSV](https://data.bis.org/bulkdownload)中的 `WS_EER_csv_flat.zip`。基础快照只取月度（`M`）、宽口径篮子（`B`）、名义（`N`）和实际（`R`）系列。BIS 同时提供日度名义值及其他篮子，这些序列未进入当前快照。两类指数基期均为 **2020=100**。

随仓库提供的快照有 63 个国家或地区及欧元区区域汇总，覆盖 1994-01 至 2026-08；名义与实际系列各 25,088 条，共 50,176 条。欧元区原始代码 `XM` 被映射为项目内部的 `XEA`，`area_type=aggregate`，不计入国家数。页面允许将其作为区域汇总对照，并明示这一身份。

## 如何解读

名义有效汇率（NEER）按贸易权重汇总双边汇率；实际有效汇率（REER）进一步用相对消费者价格调整。指数上升表示该经济体货币相对贸易伙伴**有效升值**。实际指数上升通常对应相对价格竞争力下降，但并不直接测量出口量、利润或资产回报。BIS 的权重基于制造业贸易流，不能代表一国全部金融或服务贸易敞口；具体方法以 [BIS 官方说明](https://data.bis.org/topics/EER)为准。

图表显示每个经济体自身的月度同比变化：`100 ×（当月指数 / 同一系列 12 个日历月前指数 − 1）`。只有存在同一地区、同一类型、恰好 12 个月前的观测时才计算；缺月不以邻近月份代替。表格显示所选年份内该地区该类型的最后一个实际观察月，以及原始指数和同比。不同国家的 **2020=100 指数水平不可直接用作竞争力排名**；同比只是同一系列的变化，不是即期汇率收益。名义与实际也不能互相代替。

本快照属于下载时可见的修订后历史值。BIS 可能修订历史指数、贸易权重和价格数据；尚未保存逐发布日期的实时版本，因此不能把它直接用于无未来信息的投资回测。[BIS 常见问题](https://data.bis.org/faq)说明月度系列的发布与覆盖。使用时应固定观察月、快照校验值与数据下载时间。

## 重建与核验

```powershell
python scripts/refresh_bis.py --eer-only
python scripts/refresh_bis.py --eer-only --eer-zip data/raw/WS_EER_csv_flat.zip
```

不加 `--eer-only` 时，刷新脚本将政策利率、信贷/GDP 与有效汇率三份快照整批发布。导入器流式读取压缩 CSV，检验压缩结构、系列定义中的基期、维度代码、月度日期、正指数、观测状态和唯一主键。基础快照由 `data/processed/bis_eer.parquet` 与同名 JSON 元数据组成；JSON 记录来源 URL、原始 ZIP 的 SHA-256、覆盖范围、下载时间和 Parquet SHA-256。原始 ZIP 放在被 Git 忽略的 `data/raw/`。详情见[批次发布与回退](SNAPSHOT_OPERATIONS.md)。
