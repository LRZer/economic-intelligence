# 有限补充实验协议：年度GDP研究

协议先于补充实验结果写入；不修改已运行的原始模型参数。原始2020—2024结果已经查看，
所以此补充比较是描述性复核，不称为新的未接触测试。若快照存在2025真实GDP标签，则将
2025保留为单独的额外评估年；若无标签，明确记为不可评估，不用IMF预测代替实际标签。

- 任务：在上一自然年指标齐备程度明确的条件下，研究下一年同一经济体实际GDP增速。
- 数据：同一已固定WDI快照；仅用六项原有滞后指标，增加本国过去五年GDP中位数作为基线。
- 开发：2015—2019逐年训练此前标签；方法选择只看这五年的合并MAE。
- 原留出复核：2020—2024逐年训练此前标签；所有对照使用完全相同的国家×年份目标样本。
- 强对照：上年值、过去五自然年GDP中位数（至少三项，缺失时用上年值）、固定岭回归alpha=10。
- 有限模型：原始HGB参数不变；另一候选为相同HGB学习相对五年中位数的残差。
- 预算：开发及原留出每年各一次训练；不搜索超参数，不根据原留出结果选择方法。
- 不确定性：按经济体整组重采样，2,000次、seed=42；同一个国家全部年度一起抽取。
- 地理诊断：2019年，国家代码SHA-256模5为0的经济体不参加任何训练标签；仅作开发内迁移诊断。
- 验证：重复键拒绝；特征自然年对齐；训练内填补/缩放；变动未来标签不能改变早期估计和方法选择。
- 成果口径：公布每项对照、每年MAE及覆盖、最强开发期对照与提升率。未优于强对照或年度不稳则保留实验标记。
- 局限：当前修订数据，无逐期发布日期和实时版本；跨国结构、发布滞后与疫情改变均可能影响表现。
