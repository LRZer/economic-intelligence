# 观澜整合设计与验收约定

全球研究台和中国官方观察台在独立新目录整合，原项目、提交历史及未提交修改保持。中国实现迁入 `china_macro` 命名空间，消除同名模块与测试冲突；运行数据库与包内数值材料分离。主界面统一为八个工作区，中国轻量网页保留为可选独立入口。

核心研究闭环是国家—HS2 行业下行、伙伴网络、恰好上一年宏观匹配、开发期预定参考、有限机器学习对照、完整评估与证据导出。强对照、消融和稳定性失败和通过门槛同等呈现，不以测试成绩选择推荐。

默认离线：不自动采集、不默认付费。数据来源独立失败处理；整批刷新通过事务切换；哈希或范围不一致时拒绝静默回退。所有真实来源和模型输出分别标注。

验收覆盖可复现独立环境、依赖一致、来源许可与发布清单、单位与口径、核心端到端功能、时间边界／未来扰动、同样本比较、报告范围和转义、事务回滚、付费 mock、UI 正常／空／损坏／重复导航、移动端、测试／lint／核心类型检查／构建／安全扫描。最终状态在 `ACCEPTANCE.md`，尚未实际执行的远端 CI 不称通过。

发布仅限用户批准的新 PRIVATE 目的仓库 `LRZer/economic-intelligence`。不覆盖旧仓库、不强推、不合并 PR、不部署在线服务。使用已有授权；不读取、输出令牌或创建持久新凭据。推送后须核对实际私有属性、远端提交 SHA 和该 SHA 对应 CI。
