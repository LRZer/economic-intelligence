# 多维宏观对照方法

“跨国比较”工作区可在同一 WDI 年度快照中，对最多六个经济体、七项百分比指标建立并排矩阵。默认展示实际 GDP 增长率、消费者价格涨幅、经常账户余额占 GDP、资本形成总额占 GDP 和 FDI 净流入占 GDP；还可选制造业占比、失业率、实际利率和中央政府债务占 GDP。所有指标保留各自定义，不计算跨指标合成分数。

矩阵格子显示**所选年份原值**。颜色是同一年全球有值经济体的中秩百分位：`100 ×（严格低于本值的经济体数 + 0.5 × 与本值相同的经济体数）÷ 有值经济体数`。未发布的数值保持空白；全球样本总数和每项有效数值个数在图下分别展示。高百分位只表示该指标数值较高，例如通胀、债务、FDI 和经常账户余额的经济含义不能用同一方向解释，颜色也不是经济质量或投资吸引力评分。

展开“五年前端点变化”后，系统只用所选年份和恰好五年前的原值计算**百分点差**。任一端点缺失则差值为空，不从邻近年份补齐，也不读取所选年份以后的信息。实际增长率两端点之差只表示两个年度增长率的变化，不是五年累计 GDP 增长。对低覆盖指标（有效经济体不足一半）显示提醒。

CSV 底稿保留国家代码、观察年份、指标代码、原值、全球百分位、有效样本数、五年前端点、百分点差、官方指标链接及 WDI 快照 SHA-256。来源均为[世界银行 WDI](https://data.worldbank.org/)；每项指标在页面中链接到对应的官方定义页。当前 WDI 快照不是逐项公布日和历史修订版，因此该矩阵不能用作某一历史交易日可获得信息的回放。资本形成不等同于金融资产投资；FDI 净流入也不是资产收益。

页面链接中的 `peers` 和 `profile` 参数保存所选经济体及指标代码，可把同一筛选条件交给其他研究者；重现原数值仍需相同 WDI 快照版本。

以仓库随附的 2024 年 WDI 快照为例，实际 GDP 增长率有 200/217 个经济体的有效数值，消费者价格涨幅有 174/217 个。展示这些分母，是为了让颜色所代表的相对位置能够被核对；官方快照更新后应以页面实时显示的覆盖数为准。
