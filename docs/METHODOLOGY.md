# 美国周期研究：直接官方数据与失败门槛

美国序列独立从 BLS API、美联储理事会 G.17 与 H.15 获取；没有使用旧 FRED 内容换标签或继续训练。原始 API JSON、G.17 文本、H.15 CSV、来源／季调／单位／获取日期与 SHA 保留。

| 内部代码 | 官方来源与定义 |
|---|---|
| CPI_SA | BLS CUSR0000SA0，季调 CPI 指数 |
| UNEMP_SA | BLS LNS14000000，季调失业率，% |
| IP_SA | Fed G.17 B50001，季调工业产出指数 |
| EFFR | Fed H.15，有效联邦基金利率，月均，% |
| UST2Y／UST10Y | Fed H.15，2 年／10 年国债收益率，月均，% |

GMM 仍是固定的三状态研究模型：最多 180 月滚动训练、至少 120 月、对角协方差、3 次初始化、seed42。风险标签是六个月后的工业产出水平低于本月起点；训练与评分之间保留六个月标签隔离。状态为统计聚类，不称官方经济周期判定。

295 个评估月、92 个事件。模型 Brier 0.237862，训练事件率基线 0.218742，ROC-AUC 0.5023。模型减基线 Brier 的时间块描述性 95% 区间约 `[-0.009823, 0.05070]`，未通过门槛。页面默认训练事件率基线，实验模型仅主动展开。全部逐月结果可导出。

固定逻辑回归候选在 2019 年及以后留出中也未优于基线，因此未启用。没有继续追试留出。候选的有限比较可用 `scripts/benchmark_cycle_candidates.py` 复核；与本项目其他失败结果一起保留。

数据是当前修订历史版本，不含每个当时可见版本和完整发布日期。月末未必已发布全部观测，六个月标签隔离也不解决历史修订问题。不能由此推断可实施的实时交易、资产收益或危机识别效力。Oct2025 官方缺失保留，不填造记录。

主动刷新：`python scripts/refresh_data.py --us-only`。刷新后的数据指纹会变化，必须重新评估；新快照不得冒充原固定实验。来源许可见 `DATA_LICENSES.md`。
