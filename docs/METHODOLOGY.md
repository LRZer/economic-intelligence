# 美国周期研究：直接官方数据与失败门槛

美国序列独立从 BLS API、美联储理事会 G.17 与 H.15 获取；没有使用旧 FRED 内容换标签或继续训练。原始 API JSON、G.17 文本、H.15 CSV、来源／季调／单位／获取日期与 SHA 保留。

| 内部代码 | 官方来源与定义 |

| CPI_SA | BLS CUSR0000SA0，季调 CPI 指数 |
| UNEMP_SA | BLS LNS14000000，季调失业率，% |

GMM 仍是固定的三状态研究模型：最多 180 月滚动训练、至少 120 月、对角协方差、3 次初始化、seed42。风险标签是六个月后的工业产出水平低于本月起点；训练与评分之间保留六个月标签隔离。状态为统计聚类，不称官方经济周期判定。

295 个评估月、92 个事件。模型 Brier 0.237862，训练事件率基线 0.218742，ROC-AUC 0.5023。模型减基线 Brier 的时间块描述性 95% 区间约 `[-0.009823, 0.05070]`，未通过门槛。页面默认训练事件率基线，实验模型仅主动展开。全部逐月结果可导出。

固定逻辑回归候选在 2019 年及以后留出中也未优于基线，因此未启用。没有继续追试留出。候选的有限比较可用 `scripts/benchmark_cycle_candidates.py` 复核；与本项目其他失败结果一起保留。

数据是当前修订历史版本，不含每个当时可见版本和完整发布日期。月末未必已发布全部观测，六个月标签隔离也不解决历史修订问题。不能由此推断可实施的实时交易、资产收益或危机识别效力。Oct2025 官方缺失保留，不填造记录。

主动刷新：`python scripts/refresh_data.py --us-only`。刷新后的数据指纹会变化，必须重新评估；新快照不得冒充原固定实验。来源许可见 `DATA_LICENSES.md`。


# 月度研究核验单与约束编排

`monthly-review-v1` 使用原 `china-monthly-v1`，不修改参数、评估窗口、验证期基线选择或门槛。新层将同一份输入排序／去重检查、审核指标口径、NBS HTTPS来源、有限数值和自然月期别验证后运行原模型。比较明确是读数的百分点差，PMI为指数百分点；同比/环比指标的读数差不等于价格水平增长率。缺比较月不插值。

证据分为官方观察、模型评估与异常诊断；声明另外标记确定性计算、预测、不可用和局限。预测不冒充已发布观察；Ridge经验带不属于默认基线；异常无真值标签不报告准确率或原因。默认基线继续用开发验证期预先选定方法，无论现有留出排名如何。

外部编排仅允许严格JSON的 `review_id` 与唯一 `claim_ids`；最新读数、方法决策和局限必需。任意正文／数字／额外字段／工具调用／不存在声明／旧指纹均拒绝。展示文句与数值只来自本地模板，编排本身未证明LLM业务能力。

核验包SHA绑定指标、同口径源行、比较范围、模型、声明和依赖；报告SHA另外绑定所选编排。来源链接变化即使模型数值不变也会改变核验ID。离线验证器重新拟合模型并重建全部声明，检测仅重新计算SHA的篡改；该机制不证明数据来源真实或防御恶意同步替换原始数据，不是签名。复现需同样锁定依赖与浮点环境，跨版本差异不得静默略过。

29例事先确定的工程核验在已查看数据上运行，不构成新的预测验证或自然语言质量准确率。下一阶段另设隔离gold的应用任务和拒答评估，详见 [协议](MONTHLY_REVIEW_PROTOCOL.md) 与 [路线](../ROADMAP.md)。


# 证据问答：检索、工具与应用评测

`restricted-assistant-v1`采用char TF-IDF（2—4字符ngram、sublinear_tf）能力描述路由与源行检索；先按指标和自然月过滤，检索排名不改变数字/来源。显式“差值”运算约束源于开发修正。阈值0.08在首轮封存前冻结，关键词为同题对照。没有预训练LLM、外部向量模型下载、新预测训练或因果识别。

六工具仅使用批准库与原固定模型；最新月份为库内最近统计期而非实时承诺。均值/极值限定连续完整2—24月；上月/去年同月按自然月查找，不借最近记录。模型比较只针对当前快照，历史时点问题拒绝，不重新按问题选赢家。

60开发/150封存按表述族整组隔离，独立oracle从原始行与Decimal算术构造gold；固定模型审计gold取既有输出。封存答题工作进程不接收gold路径，并阻止题库/凭据文件、网络与外部进程。13项源码/数据/协议字节指纹、问题/gold哈希与一次首轮标记留存。封存后代码保持，所有六项错误澄清如实计失败。

首轮任务正确96%，覆盖92.3%，已答数值/引用及应拒答100%；区间、原始失败、初始开发54/60及最终60/60保留于[实测](ASSISTANT_ACCEPTANCE.md)。这是已查看公共数据上的程序任务应用研究，不是新预测留出或真实LLM质量；重复模板相关性、单开发者oracle、有限能力描述限制外推。

外部计划只允许指纹、key、tool、periods、direction白名单；本地独立重新解析问题并核对范围，不能任意调用函数、读取文件或写数字。mock证明约束处理，离线文件无法证明LLM身份，外部计划导出明确`llm_used=null`。HTML/JSON/CSV与离线重算检查一致性，不证明来源真实性；LLM试点未执行。


# 真实BACI流图的有限市场压力工具

`trade-graph-v1`按同年同HS2正额贸易边建矩阵T，各出口国行归一化W；无报告后续出口行0。D=W s、I=W² s、B=(D+αI)/(1+α)，s∈[0,100]、α∈[0,1]。行和≤1保证有限压力范围；两跳质量缺口原样展示。不识别因果、投入产出系数、货物再出口或经济损失，不校准/重新预测原模型。

路径两段金额及各自归一化份额、压力、贡献和来源ID完整保留；源边/年份/HS/原包与分区指纹绑定报告。可视化截前20条与表前100条，残差明确，导出含全部。HHI按全部同业出口伙伴，1/HHI为有效数量；不同年份可选择回顾，不把权重变化当因果。S19来源类别保留，不猜成ISO国家。

预定小图金标准、反例与六个已查看真实工程案例由独立Decimal oracle核验，不是sealed预测验证或LLM质量；初始源代码契约误拒S19及协议勘误留存。最终安全检查用明确异常，不能在优化Python下移除。旧问答13文件冻结及六项失败保留，无新训练。细节和范围见[阶段三实测](TRADE_GRAPH_ACCEPTANCE.md)。
