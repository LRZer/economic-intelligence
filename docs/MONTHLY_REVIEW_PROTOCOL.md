# 月度研究核验单：阶段一冻结验收协议

这是已查看数据上的工程与应用流程核验，**不是新的预测验证集、未触及留出集或语言模型真实商业质量评估**。既有 `china-monthly-v1` 参数、时间划分、基线选择、区间方法及失败结论保持。没有新训练候选或超参数搜索。本协议在执行下述任务集前保存，并在结果中记录其 SHA256。

## 目的与确定范围

业务流程：选中国月度指标 → 选上个自然月／去年同月比较 → 实际运行既有 Ridge 和 IsolationForest → 将官方观察、确定性计算、模型评估、预测、异常和局限分型 → 生成核验单 → 导出并离线重算。

只使用已审核的七个 NBS 指标与现有许可内数据。不采集新数据、不安装新模型、不发付费请求。下一统计期估计保留原开发期选择的默认基线，不按现有留出结果选择赢家。所有字句和数值由确定性模板产生；可选外部编排只能选择已存在声明 ID，必须保留最新读数、方法决策与局限。

## 预定工程任务集（29例）

- 14例真实快照流程：七个指标 × 上月／去年同月比较。独立核对比较期、数值差、源链接、全部声明依赖；重新运行已冻结本地模型，并核验默认基线与既有结论。完整导出 JSON 离线复算通过；两种比较的模型结果必须完全相同。
- 8例预定不可信编排：额外正文、额外数字、编造声明 ID、漏掉必需局限、重复 ID、其他快照 ID、非字符串 ID、要求执行任意工具。全部必须拒绝。
- 7例篡改：每个指标各修改一个声明数值并重新计算外层及内层 SHA，复算仍须拒绝。SHA 一致本身不能替代结果复算。

单元测试另覆盖上涨／下降／持平、缺自然月不插值、缺少历史、空输入、重复月、非有限值、错误口径、URL 域名伪装、未启用付费零请求、显式凭据边界与模拟响应。它们属于回归保障，不加进真实任务成功率。

## 本阶段门槛

29例须全部通过；篡改与越权通过数为零；本阶段付费／联网模型请求为零。正常、空、异常和重复操作 UI 能安全处理；桌面及390px窄屏实际浏览器检查无未处理异常或页面横向溢出；导入错误计划保留本地单，切换指标／比较后过期计划拒绝；HTML／JSON／CSV实际下载一致，离线HTML不执行脚本。完整既有测试、Ruff、mypy、JS、安全扫描与构建通过既有门槛。Git私有性、实际提交与对应CI须核对。

## 局限与下一阶段

29例的成功是**实现约束和离线复算通过**，不是模型经济准确率、自然语言事实正确率或泛化率。不计算误导性置信区间；这些固定工程断言不是随机总体抽样。既有公开历史审计集已查看，不能重新称未触及留出。没有首次公开版本或异常真值标签。

下一阶段另锁定任务、gold隔离和预算，再评估真正的结构化检索／受限工具调用助手。开发与sealed病例分开，报告数值正确、引用支持、应拒答、越权、完成率及延迟；目标门槛预先决定，失败不得通过修改sealed病例掩盖。本阶段的模板核验不能冒充下一阶段大模型任务指标。
