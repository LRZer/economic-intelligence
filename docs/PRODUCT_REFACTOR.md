# 页面上下文与研究流程重构

## 实现范围

`app.py` 仅管理品牌框架、六项导航、中文语言声明及选定页面的执行。`src/guanlan/ui/` 将各研究任务拆成独立模块，分析与导出计算继续使用原有业务模块。没有在本轮更新、插补或替换数据快照。

| 主页面 | 有效筛选 | 来源与输出 |
| --- | --- | --- |
| 经济体概览 | 经济体、数据年度 | WDI；历史轨迹、此前十年中位数及有效期数、当前图底稿 |
| 跨国比较 | 子视图、比较经济体、指标、年度；同组参照经济体和范围 | WDI 历史、横截面、多指标与同组样本；IMF预测独立使用发布版本、预测年份和经济体 |
| 金融条件 | 专题、经济体或区域、共同期/最新可得值模式、截至期、历史范围 | BIS 月度利率、季度信贷、月度有效汇率；分别下载当前历史和比较期数据 |
| 贸易结构 | 报告经济体、贸易年度；伙伴/商品分析流向 | CEPII BACI 货物贸易；年度总额含进出口，分析流向只影响伙伴及商品 |
| 研究 | 报告经济体、年度、同组指标和范围；或固定美国的模型实验 | 可读正文、HTML/ZIP/Markdown、旧研究包差异、按需解释性摘要；模型回测独立于国家年度筛选 |
| 数据与方法 | 来源状态、覆盖检查年度、检查经济体 | 来源版本与时点、低覆盖提示、逐指标状态、字典、刷新审计和校验值 |

## 上下文与错误处理

- 页面控件使用独立键，另外保存可恢复的会话选择。URL 只反映当前有效参数；进入应用时读取一次，之后不从滞后的 URL 重置导航。[Streamlit 跨页控件说明](https://docs.streamlit.io/develop/concepts/multipage-apps/widgets)描述了临时控件键和持久状态的区别。
- 继承的经济体或年度不在目标快照中时，明确提示采用的可用选择，随后更新当前筛选与 URL；不把另一年度的读数标成原研究年度。
- 页面切换先创建空的内容占位，再执行唯一的页面模块，避免等待数据时继续保留上一页的正文。
- 来源按需加载和校验；一个 BIS、贸易或 IMF 快照失败时不阻断无关研究页。来源校验失败时不静默回退旧快照；未安装 BACI 且未设置活动引用时，才允许使用 Comtrade 公开样本。
- 数据问题显示中文状态、诊断编号和重试按钮。计算模块另有边界；原始异常保留在被 Git 忽略的 `output/diagnostics.log`。
- 中文页面声明 `lang=zh-CN`、`translate=no` 和 `notranslate`。脚本只设置根节点属性及语言元数据，不替换文本、不重写 `removeChild`，也不吞掉前端异常。
- [React 官方问题记录](https://github.com/react/react/issues/11538)支持翻译修改文本节点可能导致节点删除错误这一假设。本轮干净的内置浏览器中没有复现该错误；不能据此断定用户原浏览器的翻译扩展就是根因，也不能保证所有扩展遵守翻译标记。

## 统计与展示规范

- 统一实际GDP增速的术语；`SL.UEM.TOTL.ZS` 明确使用 [ILO 模型估计失业率](https://data.worldbank.org/indicator/SL.UEM.TOTL.ZS)。GDP 总量说明现价美元口径。
- 概览中位数只使用所选年之前十年，至少要求每项有 5 期有效观测；范围和有效期数直接可见。完整历史图可以含后续年度，但选择数据年度不是恢复当时发布版本。
- 摘要百分比保留 1 位小数，研究详情保留 2 位，CSV 保留源精度；年度转为无千位分隔的文本；缺失期不借用邻期。
- 按经济体标识固定跨图颜色，按指标固定增长及通胀颜色。增长/通胀地图采用跨年固定的零两侧分级边界及开放端点，悬浮保留极端原值；其他自动色阶明确提示不能直接跨年比色。
- 多指标表可切换原值与数值百分位。原值模式采用统一底色，不同时以背景编码百分位；另一项进入悬浮，每列标明全球有效样本 n。低覆盖仍给出提示。
- 同地区与收入组使用当前 WDI 快照中的分类，明确未恢复历史分类、未提供分类生效年度。
- 金融共同期严格匹配；各自最新模式只取截至期之前的有效记录，并标明实际期别。德国政策利率国家序列止于 1998-12；当前快照未加载欧元区政策利率，不自行代填。[BIS 口径说明](https://www.bis.org/statistics/cbpol/cbpol_doc.pdf)可用于核查货币区与国家序列。
- 有效汇率主表跟随实际/名义选择，指数基期和严格 12 个月变化口径保留；不以跨国指数水平排序。
- 模型先显示实验目标及验证状态；完整回测与 2010 年以来可切换，分别标出评估月份。红点明确为工业产出收缩事件；Brier 点估计和跨零区间分别解释，不扩写为衰退概率。
- 贸易主屏呈现货物贸易与伙伴占比；HHI、商品分类版本和原始记录量进入详情。报告正文直接显示，完整来源和快照信息保留在研究包与展开详情。

## 解释性摘要与凭据

先呈现确定性事实，再由用户主动生成摘要。发送内容可在设置中检查，目标服务为 `api.deepseek.com`。凭据从环境变量、[Streamlit Secrets](https://docs.streamlit.io/develop/concepts/connections/secrets-management)或临时会话设置读取；临时设置带清除入口，不写入仓库和数据快照。

摘要指纹包含报告 ID、事实与来源版本，研究对象、数据年度、参照设置或快照变化后会标记需要更新。旧摘要仅在明确标记过期的详情中保留。自动测试使用模拟 API，不调用付费服务。

## 验收

- AppTest 验证六个主页面和主要子视图没有应用异常或模块错误。
- 完整路径：美国 2023 年概览 → 改为 2022 年 → 跨国比较 → 贸易 → 进口伙伴 → 研究报告 → 返回概览；筛选、URL、报告及研究包参数一致。
- 验证旧 URL 不会逆转导航；旧 IMF 链接恢复经济体、指标和预测年度；模型视图移除国家年度控件；比较选择与百分位模式正确恢复。
- 验证 2000 年概览进入贸易时明确提示快照缺年并使用 2024 年；WDI 不支持的继承经济体与年度在报告页明确提示，筛选与 URL 同步。
- 模拟政策利率快照损坏后，概览和信贷专题仍能使用；验证共同期不补值、最新可得模式显示更早的有效观察期。
- 验证模拟智能摘要在更改数据年度后提示需要更新，快照与参照参数进入摘要身份。
- 真实浏览器完成概览、比较、贸易、报告、美国模型与返回切换，核对标题和来源；下载美国 2023 年 HTML 并检查研究对象、年度和预测附录。
- 浏览器语言标记已核对。第三方翻译扩展的主动改写尚需在用户原浏览器环境复核；完整键盘和辅助技术审核未在本轮宣称完成。
- 浏览器实际来源说明的透明度为 1，文字色 `#506673` 对页面背景 `#f3f6f8` 的对比度约为 5.55:1。此项检查不代表完成全站无障碍审计。

当前运行环境使用项目 `.venv`，依赖按 `pyproject.toml` 安装。测试和启动请使用其中的 Python，避免调用旧的全局 Streamlit。
