# 专业数据平台参照与观澜的界面原则

以下参考的是官方数据产品的研究工作流，不复制页面设计或代码。

| 官方产品 | 可核对的做法 | 观澜落实情况 |
| --- | --- | --- |
| [世界银行 Data / DataBank](https://data.worldbank.org/about/get-started) | 以国家和指标为入口，支持筛选、图表与原始数据下载 | 各页面仅显示适用的经济体与期间筛选；跨国页提供指标时间序列、全球同年地图、列表与 CSV |
| [IMF DataMapper](https://www.imf.org/en/Data) | 同一指标可在地图、国家列表和时间序列间切换，并对比国家与地区 | 跨国页通过子视图切换历史走势、同年横截面与多指标参照；同组参照使用地区或收入组 |
| [OECD Indicators](https://www.oecd.org/en/data/indicators.html) | 指标附定义、交互图表及完整数据入口 | 数据与方法页提供指标字典、来源、单位、比较提醒；图表附近提供 CSV 下载 |
| [FRED Graph](https://fred.stlouisfed.org/graph/) | 图表明确序列、单位、频率、来源和注释，可下载原始观测 | 研究中的美国模型实验链接每条原始序列，说明方法边界并导出逐月回测数据 |
| [BIS Data Portal](https://data.bis.org/topics/CBPOL) | 金融序列同时提供单位、频率、国家口径注释与批量下载；[信贷缺口](https://data.bis.org/topics/CREDIT_GAPS)及[有效汇率](https://data.bis.org/topics/EER)附方法口径 | 金融条件页分开利率、信贷和有效汇率，显示最新实际观察期、指数基期、区域汇总身份、缺失、序列原注释与 CSV 来源校验值 |

## 页面组织

观澜使用六项主导航和紧凑的页面专属标题。概览保留关键指标、增长主图与右侧通胀和历史参照。比较、金融、贸易与报告各自管理有效筛选与来源；IMF预测是独立版本子视图，美国模型属于研究实验，解释性摘要嵌入报告。详见[页面上下文重构](PRODUCT_REFACTOR.md)。

页面先提供当前研究对象与数据时点，再显示图表和结果。不同页面的筛选不会常驻无关模块，返回时恢复该页的选择。URL 仅保存当前有效上下文。内部代码、哈希和长表按需展开；来源、口径及覆盖限制仍可追溯。

图表使用统一的中文字体、浅色横向网格、简化工具栏和带单位的悬停提示。概览页以青色显示增长、暖色显示通胀，并用虚线和空心点标记所选年份；历史数据仍按实际年度以直线相连，不用曲线平滑制造不存在的中间观测。跨国折线图保留图例，增长/通胀地图采用跨年固定的正负分级色阶，悬浮仍为原始值。

## 当前仍需达到的专业标准

- 已在桌面和窄屏预览概览页与跨国比较页的指标卡、导航和图表；仍需完成全部工作区的键盘、触控与辅助技术验证，并继续扩展分享链接至图表层的指标及比较集合。
- 获取发布日和历史修订版本，区分数据公布时可见信息与事后修订值。
- 完整贸易数据管线、贸易镜像审计、商品分类版本管理和性能基准。
- 图表与报告提供可重复的导出格式、数据版本 ID 与自动审计结果。
- 长期评估跨国指标口径；不将当前单国月度试点作为投资信号。
- 将有效汇率纳入可核验研究包的下一版格式，统一图表下载与报告引用；当前有效汇率可从金融条件页单独导出。
