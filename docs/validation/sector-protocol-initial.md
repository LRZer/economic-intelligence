# 宏观×贸易网络：国家—行业出口下行研究协议 v1

本协议在读取行业模型留出成绩前冻结。范围、标签、模型参数、样本规则和测试年份不根据测试结果改变。
研究原型回答：在上一年行业规模、变化、伙伴集中度及伙伴宏观条件下，下一年该国HS2行业货物出口是否下降至少10%？
不是经济因果识别、资产回报预测、公司财务预测或实时交易策略。

## 数据与时点

- BACI HS17 V202601，2017—2024，官方原始ZIP的完整8年数据；单位v为千美元，金额转为美元。
- ISO3国家代码按BACI country_codes映射；HS6前两位汇总为HS2。只取01—97有效章；不把章号当有序数值特征。
- 行业出口总额按出口国×HS2×年份汇总，伙伴权重为上一自然年该行业对各进口国出口份额。
- WDI使用固定本地快照的GDP增长、通胀、失业率、资本形成及经常账户占GDP；恰好上一自然年匹配，不使用邻近年份替代。
- 两源均为当前修订历史版，没有逐次公开版本或可靠的最早发布日期。历史特征期别早于目标年，但不代表预测时实际已知。
- 伙伴宏观覆盖权重明确报告；只使用GDP匹配权重≥80%的样本，余下权重不填为零。匹配部分按覆盖权重归一化。
- 使用所有符合规则的国家×行业，不事后选择表现好的国家、行业或年份。

## 标签与样本

- 一年时距：目标year的行业出口金额 ≤ 上一年金额×0.90，标签为1；否则0。
- 上一年行业出口须≥1,000万美元；前两年须有该行业观测，供计算过去一年增长。
- 目标年的出口国必须在BACI该年有实际贸易记录。行业当年无记录只解释为“BACI未报告该行业流”，金额记0，报告其数量；不称真实经济零值。
- 特征：上一年行业出口规模、上一年行业增速、HS2类别、伙伴HHI、前五伙伴份额、伙伴GDP覆盖、伙伴加权GDP增长，及本国上述五项宏观指标。
- 缺失本国宏观特征只在训练数据内填补；标签不填补。不得加入目标年宏观值或目标年贸易权重。

## 训练与有限比较

- 目标标签最早2019（需要2017、2018的贸易历史）；2019—2020为初始训练。
- 开发验证2021、2022：逐年扩展训练，标签year严格小于预测year。
- 固定留出2023、2024：逐年扩展训练；2024训练可以使用已经发生的2023标签，此为预先规定的滚动评估。
- 基线一：截至训练截止年的全样本事件率，Beta(1,1)平滑。
- 强基线：截至训练截止年的同HS2事件率，Beta(2,2)平滑；未见行业回退全样本率。
- 可解释对照：训练内中位数填补、标准化、HS2独热编码，LogisticRegression(C=1,max_iter=1000)。
- 主模型：HistGradientBoostingClassifier(max_iter=100,max_leaf_nodes=15,learning_rate=.05,l2_regularization=10,random_state=42)。
- 固定消融：相同树模型移除全部本国及伙伴宏观特征，保留行业贸易历史和网络集中度。
- 不搜索超参数；每年训练上述三个模型，合计12次；额外一次2022开发解释和一次国家排除诊断，总计≤18次。
- 如模型不优于强基线，默认展示强基线；模型概率为实验结果，不更换标签、特征或测试期追分。

## 指标、解释与验证

- 完全相同的评估行比较Brier、对数损失、ROC-AUC、平均精确率；Brier为首要指标。
- 开发数据选定固定模型/对照参考，不根据留出成绩切换赢家。概率不做测试期重校准。
- 可靠性图固定10个等宽概率区间，报告各区间预测均值、实际发生率和数量；不保证校准。
- 逐年度、国家及HS2切片全部保留，切片至少30条方报告AUC，少样本明确标注。
- 按出口国整组重采样2,000次，seed42，比较主模型与行业事件率的Brier差；同一国家的所有行业/年度一起抽取。
- 2019—2021训练排除SHA256(ISO3)模5为0的国家，在2022这些国家上做开发内地理迁移诊断。
- 置换解释只在2022开发样本进行，固定3次重复；关联重要性不称因果。
- 通过门槛：两留出年份均降低行业基线Brier，且按国家成组的差值95%区间完全低于0；否则维持实验标记。
- 泄漏核查：训练标签年/贸易权重年/宏观特征年逐行保存；未来数据扰动不应改变早期样本或预测；国家排除诊断无标签重叠。

## 资源与证据闭环

在新的D盘专用目录逐年解压一个CSV并聚合，及时删除仅本任务生成的临时CSV；不修改原数据。
预估峰值≤5GB，启动前须有至少8GB可用空间。来源原始ZIP、聚合网络、模型协议、参数、环境版本、数据SHA、逐期结果和报告均可复现。
界面同时展示统计期别、模型验证状态、输入缺失、伙伴暴露、条件GDP冲击指数及HTML/JSON/CSV导出。
情景指数=上一年出口权重×手动指定伙伴GDP百分点冲击之和；没有贸易弹性假设，因此不输出推导的出口损失或资产收益。
