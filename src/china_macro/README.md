# 经纬 · 中国宏观经济观察台

一个可在本机运行的中国宏观经济数据获取、分析与展示系统。采集器按预设报告类型读取国家统计局月度综述与专题报告、财政部全国财政收支情况、央行金融统计报告与年度统计表，以及商务部转载海关总署的人民币和美元货物贸易表。当前定义 39 类指标，保存期别、口径和官方原文链接。网页提供单指标趋势、同口径价格同比与环比、景气、外贸及财政比较、两年和五年覆盖审计、可复算的同期差与历史分位、CSV 导出，以及可选的 DeepSeek 解读。当前仍在开发中，见 [开发路线](ROADMAP.md)。

2026-10-04 数据包含 2225 条官方来源观测。近24个月收录807/813个预期值（99.3%），近60个月2059/2088（98.6%）；覆盖统计排除尚未到计划时间、不单列月份、未启用口径及近期发布时间待确认的记录。五年窗口仍有29个待补录值：人民币出口、进口同比各11个，贷款年内累计增加额7个。缺口不填估算值，覆盖率也不等于所有数值已经人工复核。

## 快速启动

需要 Python 3.10 或更高版本。

```powershell
python -m pip install -r requirements.txt
python app.py
```

浏览器打开 <http://127.0.0.1:8000>。首次启动会先显示随项目提供的官方来源数据快照，再在后台自动抓取最新报告。以后每 24 小时自动更新一次，也可点击页面右上角的“同步数据”。SQLite 数据保存于 `data/macro.sqlite3`。快照保留原文链接，但尚未完成逐条人工复核。

主导航按阅读任务组织：总览 `/`、趋势分析 `/trends`、指标数据 `/data`、本期观察 `/insights`；辅助入口为数据状态 `/quality`、来源与方法 `/sources`。六页各有独立地址，可收藏、刷新或前进后退；旧版 `/#板块名` 链接仍可使用。

总览先区分各主题的实际数据期别和本机同步时间，再展示变化摘要、六项核心指标的短期折线及主题列表。本期观察按“变化关系、两期数字与原文、解释边界”组织，统计表可展开查看。数值上升、下降不自动代表改善或恶化；较上月差值只比较连续自然月的同指标，累计金额及跨年累计同比不直接计算。

趋势图默认近12个自然月，支持6/24个月、全部历史和自定义起止月。纵轴使用规则刻度，折线不填充面积，缺口不连线。指标选择与日期区间写入网址，可直接分享或收藏。指标数据页将搜索、分类及导出合并在工具栏；展开指标可查看发布记录和当前入库版本。“导出当前列表”仅导出筛选后的最新读数，全部历史及图表区间记录另有独立导出。

首次需要更长历史时，运行限定范围的回填。第一条命令读取国家统计局信息公开档案中 2024 年以来的精选发布；第二条读取主站历史目录中的 2021—2023 年报告。目录和文章请求之间留出至少 400 毫秒；日常自动更新只查近期目录页。

```powershell
python backfill.py --start-year 2024 --pages 50
python backfill.py --archive main --start-year 2021 --through-year 2023 --pages 67
python hydrate_dates.py --archive disclosure --start-year 2024 --pages 50
python hydrate_dates.py --archive main --start-year 2024 --through-year 2024 --pages 67
python backfill_annual.py
python backfill_trade.py --start 202101
python backfill_fiscal.py --pages 3 --start-year 2021
python backfill_nbs_gaps.py
python backfill_finance.py --start-year 2021 --through-year 2026 --pages 20
python cny_trade.py
```

`--pages` 是需要检查的发布目录页数。随着档案翻页或发布时间增长，应先查看实际目录覆盖范围；命令只会抓取预设的全国性报告类型。已收录的文章默认跳过，可加 `--reparse` 重新解析。两个 `hydrate_dates.py` 命令只用官方目录给已有观测补齐空缺的发布日期，不重抓文章或改动数值。历史文章的网址曾随网站迁移而重建，因此采集器以报告标题和目录显示的原始发布日期确定期别。`backfill_trade.py` 一次读取指定起始月以来的全国美元进出口金额和商务部表内同比，按月校验进出口总额及差额；`backfill_fiscal.py` 读取财政部全国报告归档。日常更新也会读取近期财政报告与外贸表。商务部原始接口响应及财政部原始文章保存在 `data/source_snapshots/`，以 SHA-256 命名，并可由 `audit.py` 重新解析对照入库值。数据状态页逐项列出近 24 个月的缺口及五年覆盖率，并将已知尚未到发布日期的期别单列。原值发生变更时，SQLite 的 `observation_changes` 表保留变更前后数值与发现时间；`ingestion_runs` 表记录采集成功、部分成功或失败及原因。

统计局网站有时会返回 HTTP 200 的 JavaScript 验证页。采集器将它识别为来源访问失败并暂停本批剩余文章；历史回填默认遇到任何来源错误就不写入本批次数据。若需要保留已解析的有效文章，可显式加 `--allow-partial`，面板会标明部分成功。请稍后通过正常网站访问途径重试，并以质量页核查缺口；不要把一次命令成功执行等同于全量覆盖。

年度固定资产投资、房地产开发和工业利润报告在次年 1 月发布，全年累计同比记为前一年 12 月；报告中另外写出的“12 月份”单月同比不会混入累计序列。`backfill_annual.py` 只重读这些精选年度报告，兼容历史报告对民间投资和商品房销售面积的不同表述。

`backfill_finance.py` 读取央行目录实际提供的翻页地址、精选金融统计报告和年度社会融资规模存量表；以表头和总量行提取官方同比。M1旧口径截止2024年12月，新口径含2024年官方回溯值及2025年后的报告，两条序列分别展示。贷款只收录原文明确给出的年内累计增加额。人民币外贸补缺优先使用商务部转载海关总署的全国人民币月表，核验币种、单月同比列及总额与差额，已收录期别默认跳过。转载日期与海关原始发布日期分别标注。Windows 上请求库遇到该来源的 TLS 握手问题时，使用系统 curl 的正常证书验证。

可先预览并离线重放随项目提供的金融来源：

```powershell
python backfill_finance.py --offline bundled_snapshots --preview
python backfill_finance.py --offline bundled_snapshots
```

金融原文、年度表和人民币外贸原始响应均保存在 `data/source_snapshots/`，随演示包提供对应原文、SHA-256 摘要和解析清单。离线回填在整批重放验证通过后才写入数据库；同一指标期别优先采用年度表中的官方修订，原值变动仍保留修订记录。

在 macOS 或 Linux 上使用 `python3 -m pip install -r requirements.txt` 和 `python3 app.py` 即可。

## DeepSeek 接入

将 `.env.example` 复制为 `.env`，填入自己的 `DEEPSEEK_API_KEY`，然后重启服务。在“本期观察”页点击“生成观察摘要”。密钥仅由 Python 服务端读取，不进入版本控制；浏览器只接收生成的文字。可通过 `DEEPSEEK_MODEL` 覆盖默认的 `deepseek-flash`。

DeepSeek 请求只包含筛选后的指标名称、数值、统计期别、口径、覆盖信息、允许的连续月份比较和官方出处，不发送网页全文。摘要明确标注模型、生成时间、数据快照及“未人工审核”；引用可跳转两期原文。数据或摘要规则更新后，旧版本收起并提示重新生成，历史内容仍保存在 SQLite。重复同步相同数值和出处不使摘要失效，数值、出处或发布日期修订会改变快照。同步及重复生成时禁止启动新的生成请求。

“本期观察”中的“查看统计依据”不依赖 DeepSeek：同期差取本期已发布读数减去 12 个月前同指标读数，单位为百分点；历史分位使用最近 60 个自然月已收录值的中秩，仅在至少 24 期且窗口覆盖率达到 70% 时显示。它们是对已发布同比、环比增速或指数水平的描述，不是从价格指数重新计算涨幅、预测或因果分析。每项比较提供本期与去年同期的原文链接。

## 发布计划与记录状态

数据状态页默认显示需关注的指标，以近24个月状态带定位缺口；点击月份可核查状态、计划时间、判定依据及已收录原文。指标总数和覆盖率作为次要信息，修订与采集记录可展开查看。

已接入[国家统计局2026年主要统计信息发布日程](https://www.stats.gov.cn/xxgk/sjfb/fbrcb/202512/t20251224_1962137.html)，分别处理价格、PMI、工业利润及主要月度指标。计划时间采用北京时间，包括2026年2月PMI延后至3月4日的安排。计划可以调整：未到计划时间为“待发布”，已到计划时间且没有收录为“待补录”，后者不证明实际已经发布。近期没有核实到发布计划的金融、财政和外贸数据为“发布时间待确认”，暂不计缺失。

覆盖率分母只包括已收录及待补录期别，排除待发布、发布时间待确认、不单列的月份及未启用或已结束的口径。目前发布计划仅核实到2026年，其他年度和机构的固定发布日仍需补齐；历史待补录状态不等于逐期核实过实际发布。

## 指标与筛选逻辑

| 主题 | 指标 |
| --- | --- |
| 增长与需求 | 规模以上工业增加值、工业企业利润、社会消费品零售总额、固定资产投资、民间投资、制造业投资、基础设施投资（按新旧口径分列） |
| 房地产 | 房地产开发投资、新建商品房销售面积 |
| 外贸 | 出口额、进口额：国家统计局及商务部转载海关总署的人民币口径同比；商务部美元口径单月金额及同比 |
| 财政 | 一般公共预算收入与支出、税收收入、政府性基金预算收入、国有土地使用权出让收入：年内累计金额与官方累计同比 |
| 价格与就业 | CPI 与 PPI 的全国月度同比及环比、城镇调查失业率 |
| 景气 | 制造业 PMI、制造业新订单指数、非制造业商务活动指数 |
| 货币与融资 | M1（新旧口径分列，新口径含官方回溯）、M2、社会融资规模存量、年内累计人民币贷款增加额 |

采集过程限制在五个官方数据域名、预设的报告标题类型和数值提取规则。没有匹配到来源、期别和有效数值的条目不会入库。抓取失败时保留已有数据，并在页面提示；缺失月份不自动补值。人民币外贸的已核实缺口会在质量页与逐月记录中说明当前统计局综述的披露方式，并链接核查原文；这不代表海关未发布相应数据。官方报告调整排版或表述时，可能需要更新 `collector.py` 或 `fiscal.py` 中的提取规则。商务部月度表注明数据来自海关总署，其[开放数据目录](https://xwfbh.mofcom.gov.cn/front/data/detail?id=D7D75F4F90DE390DB554344043AED5FC)将该资源列为完全开放。美元源表未给每月独立的发布日期，系统保留空值和抓取时间；人民币转载表给出的日期标注为网页转载日期，不冒充海关原始发布日期。财政部报告日期优先取原文标注，归档与文章 URL 仅作回退，2022 年同时公布退税调整后和自然口径增速时，系统选用自然口径，保留该年度的口径提示。

央行网站及商务部数据中心当前的 `robots.txt` 对通用爬虫标记为 `Disallow: /`。本项目已有低频本地原型和历史演示数据；公开部署或扩大这两个来源的自动采集前，应确认网站使用要求并优先争取正式数据接口或授权。国家统计局“国家数据”接口当前返回访问限制，本项目不绕过验证。

**口径提醒：**“单月金额”“单月同比”“单月环比”“年内累计金额”“年内累计同比”“月末存量同比”和“当月水平”不可混为一谈。人民币与美元外贸增速分列，不能直接拼接；美元同比取源表发布值，不用金额重算。财政收入与支出涉及不同预算科目，两者的差额不能直接当作完整财政赤字。2022 年财政收入同比采用报告中的自然口径，受大规模留抵退税影响，跨年比较时应查看原文。2026 年基础设施投资统计范围发生变化，系统将新旧口径分成两个指标，不连接成一条趋势。房地产销售面积在 2024 年以前的报告中多称“商品房销售面积”，后续报告称“新建商品房销售面积”，历史比较时须查看原文定义。页面趋势图按自然月定位；待补录期别以竖线提示，间断数据不连线，可展开逐月记录核对原文并导出当前区间 CSV。M1从2025年1月启用修订口径，央行同时公布2024年官方回溯同比；旧口径和新口径作为两个指标，趋势图与统计分析分别计算。

## 数据与文件

- `collector.py`：官方报告发现、限定抓取和数值提取。
- `backfill.py`：按年份和目录页数进行一次性历史回填。
- `backfill_annual.py`：针对年末累计报告的定向重读与回填；可用 `--year 2023` 只重读某一年度。
- `backfill_nbs_gaps.py` 和 `nbs_gap.py`：从已定位的国家统计局专题及国民经济综述原文补齐投资、房地产、价格、人民币外贸、失业率、PMI 和零售的精选缺口，保存可重放的 HTML 原文与 SHA-256 摘要；源页缺失时整批拒绝入库，可显式使用 `--allow-partial` 接受已核实部分。价格报告的全国主表与正文同时给出数值时必须一致。季度或全年综述只有明确写出当月出口和进口同比时才收录为单月值；1—2 月累计增速不会拆成 1 月和 2 月。
- `hydrate_dates.py`：根据官方目录补齐已有观测的空缺发布日期。
- `trade.py` 和 `backfill_trade.py`：读取并核验商务部美元外贸月度表，保存原始响应及校验摘要。
- `fiscal.py` 和 `backfill_fiscal.py`：限定财政部全国报告，提取五项累计金额及其官方同比，保存原始文章与摘要。
- `finance.py` 和 `backfill_finance.py`：央行金融报告、年度社融存量表与2024年M1新口径回溯；按统计口径分列并保存可重放的原文。
- `cny_trade.py`：商务部转载海关总署的人民币全国月度表，精选缺口补录及日常增量采集。
- `quality.py`：逐指标计算近 24 与 60 个月的预期发布期别与缺口。
- `analysis.py`：可复算的同期差、经验分位与三项 PMI 读数计数。
- `audit.py`：只读审计来源域名、日期、数值范围、SQLite 完整性、覆盖率及金融、外贸、财政、国家统计局定向回填的原始快照与入库值；可用 `python audit.py --output audit_report.json` 生成报告。
- `backup.py`：对运行中的 SQLite 数据库创建备份，检查完整性，并实际恢复到临时数据库核对观测数量和 SHA-256 摘要。
- `catalog.py`：精选指标定义、分类、单位与口径。
- `app.py`：HTTP API、SQLite、定时更新和 DeepSeek 服务端请求。
- `web/`：无需前端构建工具的响应式面板；`chart_model.js` 单独计算自然月窗口与逐月记录状态。
- `demo_data.json`：可离线展示的来源数据快照，包含出处和抓取日期，尚未逐条人工复核。
- `bundled_snapshots/`：随演示数据包分发的央行、财政部、国家统计局原始文章和年度表与商务部原始响应；新环境运行 `audit.py` 也可离线核对数值。

CSV 导出地址为 `/api/export.csv`。导出的每条记录都带期别、口径、来源标题、官方链接、日期类型及抓取时间，可用于后续研究。项目默认只监听 `127.0.0.1`；如需放到公开网络，请先添加认证、访问控制和任务队列。

运行 `python audit.py --output data/audit_report.json` 生成只读数据审计报告；可加 `--as-of 2026-10-04T00:00:00+08:00` 固定覆盖率的核查时间；运行 `python backup.py` 在 `data/backups/` 创建数据库备份及同名 `.json` 校验清单。备份命令会对副本进行恢复检查，不需要停止网页服务。建议在重大回填或迁移前后各执行一次。

回归检查：`python -m unittest discover -s tests -q`、`node tests/test_chart_model.js`、`node --check web/app.js`。图表日历测试不需要前端构建工具。

## Docker 运行

```sh
docker build -t china-macro-observatory .
docker run --rm -p 127.0.0.1:8000:8000 -v macro-data:/app/data china-macro-observatory
```

若在容器中启用 DeepSeek，请通过运行环境注入 `DEEPSEEK_API_KEY`，不要将密钥写入镜像。
